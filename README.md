# Local Modbus Mapping Test Tool

Windows 桌面版 Modbus RTU 485 从机模拟器和协议映射网关测试工具。

## 软件用途

本软件用于模拟一侧的 Modbus RTU 从机，并通过另一串口模拟上位机/主站访问，方便验证两路 485 之间的协议映射、地址转换、寄存器长度转换、读写功能码和返回值。

典型连接方式：

```text
上位机测试串口 ── 485 ── 协议映射网关 ── 485 ── 本软件的从机串口
```

软件包含两个角色：

1. 从机模拟器：监听从机串口，接收 Modbus RTU 请求并返回响应，或修改本地寄存器值。
2. 本地回环测试器：使用另一串口模拟上位机，通过网关发送请求，并验证返回结果。

## 主要功能

- 配置串口号、波特率、校验位、停止位、数据位和从机地址。
- 配置线圈、离散输入、保持寄存器、输入寄存器。
- 为每个寄存器设置标签、地址、映射地址、长度、默认值。
- 实时显示编号、标签、类型、地址、映射地址、寄存器长度、当前值和默认值。
- 支持双击编辑单条寄存器。
- 支持启动前将所有当前值恢复为默认值。
- 配置持久化，自动保存到 `registers.json`，启动时自动加载。
- 支持本地回环测试、测试次数、测试间隔和响应超时。
- 支持自定义测试类型和操作：单读、单写、连续读、连续写。
- 测试日志显示发送帧、返回帧、期望值、实际值、错误码和结果。
- 成功日志为绿色，失败日志为红色。

## 软件架构

程序使用 Python、Tkinter 和 pyserial 实现，当前主要代码集中在 `main.py`。

### Device：从机协议引擎

`Device` 负责寄存器数据、串口线程和 Modbus RTU 协议处理。启动后会在后台线程中：

1. 读取串口缓存。
2. 根据从机地址过滤帧。
3. 根据功能码确定帧长度。
4. 校验 Modbus CRC16。
5. 解析地址、数量和数据。
6. 读取或修改本地寄存器。
7. 生成响应帧并发回串口。

CRC 使用 Modbus 标准算法，CRC 低字节在前。

### App：图形界面

`App` 使用 Tkinter/ttk 构建深色界面，负责串口参数、寄存器配置、总览刷新、日志显示、状态控制以及回环测试窗口。串口收发和测试过程使用后台线程，主界面使用事件队列刷新，避免阻塞。

## Modbus RTU 功能码

| 功能码 | 名称 | 类型 | 作用 |
|---|---|---|---|
| `01` | Read Coils | 线圈 | 读取线圈 |
| `02` | Read Discrete Inputs | 离散输入 | 读取离散输入 |
| `03` | Read Holding Registers | 保持寄存器 | 读取保持寄存器 |
| `04` | Read Input Registers | 输入寄存器 | 读取输入寄存器 |
| `05` | Write Single Coil | 线圈 | 写单个线圈 |
| `06` | Write Single Register | 保持寄存器 | 写单个保持寄存器 |
| `0F` | Write Multiple Coils | 线圈 | 写多个线圈 |
| `10` | Write Multiple Registers | 保持寄存器 | 写多个保持寄存器 |

线圈按 Modbus 标准低位在前（LSB First）打包；寄存器使用高字节在前的 16 位数据格式。单线圈写入只接受 `FF00`（置位）和 `0000`（复位）。

## 寄存器配置

### 地址与类型

地址使用 Modbus PDU 地址，范围为 `0-65535`，界面显示十进制，不自动转换 `40001`、`30001` 等参考地址。

- 线圈：可读可写，值为 0 或 1。
- 离散输入：只读。
- 保持寄存器：可读可写，每个值为 0-65535。
- 输入寄存器：只读，每个值为 0-65535。

### 寄存器长度与默认值

寄存器长度默认是 1。长度大于 1 时表示该配置项占用连续多个地址。默认值数量必须等于长度，每个值范围为 `0-65535`。

例如长度为 4 时填写：

```text
100,200,300,400
```

而不是只填写一个值。程序会根据长度生成多寄存器读取或写入帧。

### 映射地址

“地址”表示从机模拟器本地地址，“映射地址”表示网关/上位机侧地址。本地回环测试使用映射地址生成测试帧，网关应将其转换到从机侧地址。

示例：

```text
本地地址：5000
映射地址：6400
长度：1
```

## 单独操作与连续操作

“单读/单写”表示只操作一个配置项，但仍然根据该配置项长度选择功能码：

- 长度为 1：使用单线圈或单寄存器功能码。
- 长度大于 1：使用多线圈或多寄存器功能码，完整操作该项的全部长度。

“连续读/连续写”会尝试合并同类型且映射地址连续的配置项。例如：

```text
A：地址 100，长度 1
B：地址 101，长度 2
```

连续操作会生成起始地址 100、数量 3 的一条请求。

## 本地回环测试

回环测试窗口可设置：

- 测试串口及串口参数。
- 从机地址。
- 超时时间（ms）。
- 测试次数。
- 测试间隔（ms）。

自定义测试选项包含：

- 线圈：单读、单写、连续读、连续写。
- 离散输入：单读、连续读。
- 保持寄存器：单读、单写、连续读、连续写。
- 输入寄存器：单读、连续读。

测试流程：

1. 根据勾选项选择寄存器和操作。
2. 根据地址和长度生成单个或多个寄存器请求帧。
3. 附加 Modbus CRC16 后发送到测试串口。
4. 等待网关返回，超过超时时间记录为无响应。
5. 校验从机地址、功能码、CRC 和返回数据。
6. 更新成功次数、成功率和测试日志。

日志中的错误码：

- `0`：成功。
- `01`、`02` 等：Modbus 异常码。
- `无响应`：超时未收到完整返回帧。
- `CRC错误`：返回帧 CRC 不正确。
- `值不一致`：帧正确但实际值与期望值不同。

## 配置持久化

寄存器配置保存在程序目录下的：

```text
registers.json
```

文件保存类型、地址、映射地址、长度、当前值、默认值和标签。旧版本配置没有长度或标签时，会自动补默认值。

## 安装与运行

环境要求：Windows 10/11、Python 3.10 或更高版本、USB 转 485 设备。

命令行运行：

```powershell
python -m pip install -r requirements.txt
python main.py
```

也可以双击 `启动模拟器.bat`，脚本会检查 Python、安装 `pyserial` 并启动程序。

## 推荐使用流程

1. 连接 USB 转 485 设备并确认串口号。
2. 打开软件，刷新串口并设置从机参数。
3. 打开“配置寄存器”，添加寄存器及其映射地址、长度和默认值。
4. 保存配置，必要时点击“重置寄存器值”。
5. 点击“启动模拟”。
6. 通过网关或上位机访问从机模拟器。
7. 需要验证映射时，打开“本地回环测试”，配置测试串口和测试选项。
8. 根据发送帧、返回帧、错误码和成功率定位问题。

## 注意事项与排查

- 启动模拟后不能修改寄存器配置，也不能重置寄存器值。
- 回环测试串口不能和从机模拟串口使用同一个串口。
- 从机地址必须与实际请求帧中的地址一致。
- 大量“无响应”时，优先检查串口号、485 A/B 线、波特率、校验位、停止位和地址。
- 出现 Modbus 异常码时，检查功能码是否适合寄存器类型以及地址映射是否正确。
- 多值默认值必须使用逗号分隔，并且数量必须等于寄存器长度。
